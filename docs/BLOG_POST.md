## 2. 본문
공용 및 교실 환경의 편리한 디지털 수업을 위해 개발된 **『아비캠뷰어 (AhBiCamViewer)』 v1.4.0**이 정식 출시되었습니다!

시중의 비싼 전용 실물화상기 하드웨어나 무거운 전용 프로그램 없이도, 컴퓨터에 연결된 모든 USB 웹캠이나 **선생님이 가지고 계신 스마트폰을 즉시 최고 성능의 실물화상기**로 변신시켜 줍니다.

이번 **v1.4.0**에서는 **듀얼모니터 확장**, **돋보기·스포트라이트 마우스 휠 크기 조절**, **형광펜 전용 색상 선택**, **카메라 상세 진단**, **전체화면 메뉴 자동 해제**, **클린 캡처/녹화**(메뉴 제외) 등 12가지 핵심 기능이 대폭 추가되었습니다.

---

## 3. 업데이트 (v1.4.0 핵심 변경사항)

### 🆕 신규 기능
* 🖥️ **듀얼 모니터 프레젠테이션 모드**: 카메라 영상을 보조 모니터에 전체화면으로 확장하여 학생용 대형 화면에 투사
* 🔍 **돋보기/스포트라이트 마우스 휠 크기 조절**: 마우스 휠 업/다운으로 실시간 크기 확대/축소
* 🖌️ **형광펜 전용 색상 팔레트**: 펜 색상과 별도로 형광펜 고유 색상 선택 가능
* 📌 **좌측/하단 메뉴 고정핀 (Pin/Unpin)**: 고정핀 해제 시 아코디언식 자동 접힘 메뉴로 전환
* 📋 **카메라 상세 진단 모달**: 인식된 카메라의 UVC 하드웨어 세부 정보, 지원 해상도, 하드웨어 제어 능력 확인
* ⛶ **전체화면 메뉴 자동 해제**: 전체화면 진입 시 모든 메뉴 고정 자동 해제, 복귀 시 복원
* 📸 **클린 캡처**: 메뉴·UI 요소 없이 순수 카메라+판서만 캡처
* ⏺️ **클린 녹화**: 오프스크린 캔버스 합성 엔진으로 메뉴 없이 카메라+판서만 녹화, REC 인디케이터 표시
* 🔐 **카메라 자동 허용**: `--use-fake-ui-for-media-stream` 플래그로 카메라 허용 팝업 자동 처리

### ✨ 개선 사항
* 🎯 **해상도 변경 시 스트림 유지**: `track.applyConstraints`로 카메라 재연결 없이 해상도 즉시 변경
* 📱 **하단 메뉴 반응형 레이아웃**: 창 크기에 따라 자동 줄바꿈되어 잘림 없이 표시
* ⌨️ **S 단축키 캡처**: `S` 키로 즉시 화면 캡처

### 📦 이전 버전 기능 (v1.0.0 ~ v1.3.1)
* ⚡ 오프라인 / USB 유선 웹캠 전용 최적화
* 🔦 스마트폰 하드웨어 플래시(조명) On/Off
* 🎯 탭 투 포커스 (Tap-to-Focus)
* ☀️ 센서 노출(Exposure) 다이얼
* 📱 스마트폰 전/후면 카메라 및 핀치 줌
* 🖥 4K UHD / FHD 1080p 고해상도 지원
* ⏱ 수업 타이머 / 스톱워치
* ✏️ 펜, 형광펜, 도형, 텍스트 판서 도구
* 📄 A4 PDF 일괄 변환
* 🔲 모눈종이/줄노트/도트 오버레이
